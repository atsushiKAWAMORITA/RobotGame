# 工房仕様

## 1. 概要

工房は、ロボットのフレーム、装甲、剣、アビオニクスなどの製作や、機体のチューニング、修復を担う専門組織である。工房ごとに得意分野が異なる。プレイヤーはゲーム開始時にDefault Workshopを持ち、専門工房の技術や製品を機体づくりに活用する。

## 2. 工房の種類と得意分野

| 工房 | 役割・得意分野 |
| --- | --- |
| Default Workshop | ゲーム開始時に所属する工房。専門分野は定義されていない。 |
| Blaze Workshop | 高出力エンジンの製作を得意とする。 |
| Iron Workshop | 重装甲の製作を得意とする。 |
| Sord Workshop | 剣の製作を得意とする。 |
| Tuning Workshop | 機体のチューニングを得意とする。 |
| Repair Workshop | 機体の修復を得意とする。 |
| Frame Workshop | フレームの製作を得意とする。 |
| Avionics Workshop | レーダーなど、航法・通信・制御・表示システムの製作を得意とする。 |

## 3. 工房レベル

工房のレベル体系は未定義である。レベル数、昇格条件、経験値、レベルごとの機能や性能差は設定されていない。

プレイヤーはDefault Workshopに所属してゲームを開始し、その後は複数の専門工房に同時所属できる。専門工房には条件や加入費用なしでいつでも加入できる。Default Workshopからの離脱可否は未定義である。

## 4. 得意分野の適用

各工房の得意分野は、対応する機体部品または作業の専門性を示す。たとえば、Blaze Workshopは高出力エンジン、Iron Workshopは重装甲、Repair Workshopは修復を担当する。

得意分野による具体的な性能補正、品質差、製作可能品の制限、作業時間の差は未定義である。

## 5. パーツの継承・流用ルール

- プレイヤーは自作パーツに加えて、他者が製作したフレームや外装を自分の機体に取り入れられる。
- 機体パーツの接続規格は全機体規模で共通化されており、規格化コネクターを介して組み替えられる。
- 異なる機体規模のパーツも、機体構造が適切に支持できる場合は同一機体に組み込める。たとえば大型の脚部と小型の胴体を組み合わせられる。
- エンジンの搭載位置は頭部1基、胸部2基、左右のふくらはぎ側に各1基までとする。
- 工房やパーツの製造元が異なることによる接続互換性の例外は設けない。
- 完成した作成品は経済仕様に従い、作成者が価格を設定して販売できる。設計データの複製・譲渡、継承に必要な条件、工房間の技術継承は未定義である。

## 6. 製造ボーナス

工房ごとの得意分野は定義されているが、製造ボーナスの具体的な数値や計算方法は未定義である。品質、性能、製作コスト、製作時間などへの補正は、追加ルールが定まるまで適用しない。

## 7. 経済への影響

工房は機体部品や装備の製作、チューニング、修復を通じて、プレイヤーの機体構築と決闘後の再出撃を支える。プレイヤーは工房製品、自作パーツ、他者製パーツを組み合わせて機体を整備できる。

決闘による損害は修復費用につながる。Repair Workshopは修復を得意とするが、修復費の割引や費用差は定義されていない。資産を超える損害を避ける損失上限があり、上限に達した場合は白旗を出して決闘を終了できる。

工房の利用料金、部品価格、売買・報酬、工房間の取引、製造による利益、経済バランスの数値は未定義である。
