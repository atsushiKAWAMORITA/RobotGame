# プレイヤー行動フロー仕様

## 1. 概要

本仕様は、プレイヤー登録から工房決定、エンジン取得、ロボット作成、決闘、戦闘後の報酬・精算までの基本フローを定義する。数値や取得条件が他仕様で未定義の箇所は、確定ルールと混同しないよう明示する。

## 2. 基本フロー

1. プレイヤー登録
2. 初期工房の決定
3. エンジンの選択・取得
4. ロボットの作成・出撃準備
5. 決闘
6. 勝敗判定と戦闘後処理
7. 報酬・修復費の精算
8. 機体を整備して次の決闘へ

## 3. プレイヤー登録

プレイヤーはゲームを開始するために登録し、プレイヤーとしての識別情報を作成する。

登録に必要な項目、認証方式、プロフィール項目、複数プレイヤー間の対戦相手選定方法は未定義である。

## 4. 工房の決定

ゲーム開始時の工房はDefault Workshopとする。プレイヤーは工房の得意分野を利用して機体部品や作業を選ぶ。

工房には以下の専門分野がある。

| 工房 | 得意分野 |
| --- | --- |
| Default Workshop | ゲーム開始時の工房。専門分野は未定義。 |
| Blaze Workshop | 高出力エンジン。 |
| Iron Workshop | 重装甲。 |
| Sord Workshop | 剣。 |
| Tuning Workshop | チューニング。 |
| Repair Workshop | 修復。 |
| Frame Workshop | フレーム。 |
| Avionics Workshop | レーダーなどの航法・通信・制御・表示システム。 |

プレイヤーはDefault Workshopに所属して開始し、その後は複数の専門工房に同時所属できる。専門工房には条件や加入費用なしでいつでも加入できる。Default Workshopからの離脱可否は未定義である。工房利用費は未定義であり、得意分野による具体的な製造ボーナスも適用条件・数値ともに未定義である。

## 5. エンジンの選択・取得

ゲーム開始時、プレイヤーは最低スペックの完成ロボットを5台無償で受け取る。27m級、35m級、45m級を1台ずつ含み、残り2台のサイズはプレイヤーが選択する。各機体には戦闘に必要なすべての構成要素が搭載され、Default Engineと標準心臓も含む。決闘報酬や製作の対価を蓄積した後、プレイヤーは機体のチューニングや高性能部品・エンジン・心臓への交換を行える。

エンジンを交換・購入する場合、プレイヤーは搭載するエンジンを選ぶ。基本となるエンジン種別は次のとおり。

| エンジン種別 | 主な特性 |
| --- | --- |
| 高回転型 | 最高速度を重視する。 |
| 高トルク型 | 加速を重視する。 |
| 省エネ型 | エネルギー効率を重視する。 |

エンジンの性能評価には最大出力、最大トルク、効率、質量、耐久値を用いる。種別ごとの係数や基準値は`specs/engine_spec.md`の暫定計算モデルに従い、数値確定後に調整する。

Default Engine以外のエンジンの購入価格、製作条件、工房との対応関係は未定義である。Blaze Workshopは高出力エンジンを得意とするが、他の工房では特定種別を取得できないという制約は定められていない。

## 6. ロボットの作成・出撃準備

プレイヤーはフレームを基礎に、外装・装甲・システム・武装を組み合わせてロボットを作成する。

### 作成手順

1. 27m級、35m級、45m級から機体規模を選ぶ。
2. フレームを用意する。自作または他者製のフレームを利用できる。
3. 全機体規模共通の規格化コネクターを介してエンジン、外装、装甲、アビオニクスを組み合わせる。異なる機体規模の部位も構造的に支持できれば混在可能とする。エンジンは頭部1基、胸部2基、左右のふくらはぎ側に各1基まで搭載できる。
4. 決闘用の剣を装備する。剣の意匠には西洋風、東洋風、日本刀風がある。
5. チューニングを行い、出力配分や機体構成を調整する。
6. 出撃前チェックを行う。

プレイヤーは出撃前に各関節への出力配分比率を数値で設定し、合計を100%にする。また、ホバーリング・高速移動・テレポーテーション共通で、心臓から高速移動ユニットへエンジン出力を何%割り当てるか設定できる。移動ユニットへ回す出力が増えるほど関節へ送れる出力は減る。蓄熱量は媒体の質量・比熱・温度から算出し、その熱量と配分率をもとにした各移動方式の利用可能時間・回数を出撃前に表示する。戦闘中にも各配分の変更指示を出せるが、容量や機体状態の制約で実行できない場合は反映されない。

各対戦の出撃前に、プレイヤーは機体ごとに補給する燃料量とRegular、Midgrade、Premiumの混合比率を決め、市場から購入して補給する。満タン補給は強制しない。既存の燃料を残したまま追加補給でき、補給後の燃料量はタンク容量を超えてはならない。試合中に消費した分だけ燃料が減り、残量は試合後も機体に保持して次の試合へ持ち越す。燃料価格とグレード倍率は`specs/economy_spec.md`に従う。

### 出撃前チェック

- エンジンの搭載数と搭載位置が規定上限内であること。
- 機体総重量がフレームの許容重量を超えていないこと。
- 補給後の燃料量がタンク容量以下であること。
- 各エンジンの使用出力がそれぞれの最大出力を超えておらず、心臓の使用出力が搭載エンジンの最大出力合計を超えていないこと。
- 決闘で使用する武器が剣であること。
- 戦闘時のエネルギー生成・消費を前提とした構成であること。バッテリー蓄電だけで戦闘を完遂する設計にはしない。

機体総重量、最高速度、加速、エネルギー消費、エンジン耐久の計算は`specs/engine_spec.md`に従う。同仕様の数式係数、機体規模ごとの上限、エンジン故障時の効果は未確定である。

## 7. 決闘

ロボットは仮想空間に存在し、プレイヤーは無人探査機のような遠隔操縦手段を通じて機体を操作する。操縦者自身はロボットに搭乗しない。

決闘中は剣のみを使用する。各試合は熱移動媒体が1000 Kまで再加熱された満充填状態から開始する。最大エンジン出力による急速加熱を制限しない。歩行以外の移動は、関節・エンジン・アビオニクス・摩擦熱など機体内の全排熱を回収して利用する高速移動ユニットで行う。ユニット通過後の熱移動媒体は約5 Kまで冷却され、全身を循環して戦闘中に発生する熱を蓄積する。テレポーテーションの使用回数はエンジン出力に比例するが、回数の計算係数と端数処理は未定義である。

対戦形式は次のとおりとする。

| 形式 | 構成 |
| --- | --- |
| 個人戦 | 1人対1人、各1機体。 |
| 個人5機体戦 | 1人対1人、各自が5機体を用いて5試合を戦う。機体は自由に選択・再使用できる。機体の損傷は次の試合へ持ち越し、試合間に費用を支払って修理できる。 |
| 5人チーム戦 | 5人対5人、各プレイヤーが1機体で1試合を戦う。 |
| 5人チーム・複数機体戦 | 5人対5人、各プレイヤーがそれぞれ5機体を用いる。各試合の前に機体を選び、再使用もできる。機体の損傷は次の試合へ持ち越し、試合間に費用を支払って修理できる。 |

5人チーム戦では剣道団体戦を参考に、先鋒・次鋒・中堅・副将・大将の5つの配置枠を設ける。チームメンバーの入れ替えは対戦前後を含めて行わず、固定メンバーで戦う。配置枠に固有能力や自動的な性能補正はなく、各チームが攻撃性能、機動性能、防御性能、継戦性能、整備性の優先度を自由に設定する。たとえば先鋒を機動力重視にも攻撃力重視にもできる。チームが勝利した場合は全メンバーの個人記録に1勝、敗北した場合は全メンバーに1敗を記録する。勝敗は機体構成、プレイヤーの操縦技量、チーム戦術によって決まる。ロボットの評価軸は機体規模にかかわらず共通とし、27m級、35m級、45m級を同じ基準で比較する。

すべての対戦はゲーム運営者が胴元として取り仕切る。個人戦では対戦申込を受けた側がファイトマネーを提示する。チーム戦では申込を受けた側の各メンバーが個別にファイトマネーを提示し、その合計をチームのファイトマネーとする。申込者または申込チームが同意した場合のみ対戦を開始する。同意後、個人戦では提示額全額、チーム戦では各メンバーの提示額が本人から対戦前に引き落とされ、返金されない。1人5機体戦では、連戦全体に対してファイトマネーを1回提示・引き落とし、シリーズ終了後に精算する。

各実戦の結果を勝利・敗北・引き分けとして記録し、連勝ボーナスは実際の連続勝利数に基づいて決める。

1人5機体戦では5試合の勝利数が多い側をシリーズ勝者とし、勝利数が同じ場合はシリーズ引き分けとする。5人チーム戦では各対戦の勝利数が多いチームを勝者とする。各プレイヤーが5機体を用いる形式では、全25試合の順番をチームが自由に決め、シリーズ開始前に確定する。開始後に試合順は変更できない。全25試合の勝利数を合計し、多いチームを勝者とする。チームの勝利数が同じ場合は代表者戦のサドンデスを決着まで行う。両チームが代表者を自由に選び、各サドンデス戦で使用する機体も変更できる。

サドンデスでは、代表機体がそれまでに負った損傷を無効にした状態で戦う。サドンデス中の損傷は勝敗判定に使うが、戦闘後に機体をサドンデス開始直前の損傷状態へ戻す。サドンデス中の損傷は通常の損傷記録や修理費に反映しない。各プレイヤーの機体選択は既定の形式に従い、チームメンバーは入れ替えない。

### 勝敗・終了条件

次のいずれかに該当した場合、決闘を終了し、勝敗を確定する。

- 剣を振れない状態になる。
- ロボットが動かなくなる。
- 資産を超える損害を避けるため、損失上限に達した時点でプレイヤーが白旗を出す。

白旗による終了は、機体を失う前に損害を抑えるための撤退手段である。損失上限の金額、判定頻度、白旗後の最終損害計算は未定義である。

## 8. 勝敗確定・報酬・精算

決闘終了後、勝敗と機体の損害を確定し、修復費用を含む戦闘後の資産精算を行う。プレイヤーは精算結果を確認して、修理・再構成を行う。

報酬獲得を含む戦闘後フローは次の順序とする。

1. 勝敗と決闘終了理由を確定する。
2. 機体損害と修復に必要な費用を算出する。
3. 勝者が確定した場合は、申込を受けた側が負担した基準ファイトマネーを勝者側へ支給し、該当する個人・チーム連勝ボーナスを別途加算する。ボーナスは胴元が負担する。勝者が決まらない場合は、引き落としたファイトマネーを参加者間で均等に分配する。
4. 報酬と修復費用を反映した資産状況を表示する。
5. プレイヤーは機体を修理・調整し、次の決闘に備える。

対戦報酬に加え、剣、ロボット、エンジン、アビオニクスなどを製作して対価を得る収入経路を設ける。これらのCRは機体のチューニングや高性能エンジンの購入に使用できる。ファイトマネーと連勝ボーナスの計算は経済仕様に従う。

ファイトマネーは勝者への報酬であり、修理費は含まない。各プレイヤーは自分の機体の修理費を別途負担する。

## 9. 繰り返しプレイ

戦闘後、プレイヤーは工房製品、自作パーツ、他者製パーツを使って機体を修理・再構成し、再び決闘へ進む。成長は機体構築、チューニング、工房の技術や流派の知識の活用を中心とする。

経験値、プレイヤーランク、工房レベル、報酬による解放、エンジンやパーツのアンロック条件は未定義である。

## 10. 未確定事項

- 登録情報、認証方式、対戦相手の決定方法。
- Default Workshopからの離脱可否、工房利用費。
- エンジンおよび機体パーツの初期所持・取得・製作・購入ルール。
- 機体規模ごとの性能差、フレーム許容重量、接続互換性。
- 戦闘後報酬の有無、種類、金額、算定条件。
- 修復費用と損失上限の計算、白旗後の精算。
- 経験値、ランク、工房レベルなどの成長・解放条件。
